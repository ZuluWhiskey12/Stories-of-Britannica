# Workflow

## Main rule
Twine is the source of truth for passages and story structure.

VS Code is used to edit CSS, JavaScript, notes, and assets.

## Change loop
1. Create a new Git branch.
2. Edit CSS/JS in VS Code.
3. Paste CSS/JS into Twine Story Stylesheet or Story JavaScript.
4. Test with Play.
5. Export HTML to exports/Stories of Britannica.html.
6. Commit and push.
7. Merge after testing.

## Do not
Do not edit the exported HTML directly unless making a small emergency fix.
